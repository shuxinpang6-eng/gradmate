# 毕业流程与关键节点（研途知识库③）

> 适用人群：研究生新生
> 内容：典型硕士时间线、每个节点是什么、毕业硬条件、常见风险
> 重要提醒：各校差异很大，本文以"典型 3 年制学术硕士"为例，**具体时间以学校培养方案和学院通知为准**

---

## 一、整体时间线（典型 3 年制硕士）

```
研一上：课程学习 · 确定导师 · 定研究方向 · 开始读文献
研一下：课程 · 文献综述 · 确定论文选题
研二上：开题（开题报告 + 开题答辩）
研二下：中期检查（汇报进展）
研三上：预答辩 → 盲审 / 外审
研三下：正式答辩 → 修改 → 提交最终版 → 学位申请 → 毕业
```

- 2 年制 / 2.5 年制：把研二、研三的节点相应提前，逻辑一样。
- 9 月入学，一般 6 月毕业；具体以学校校历为准。

---

## 二、每个节点是什么、要做什么

### 1. 开题（一般研二上，最关键的节点之一）
- 做什么：写**开题报告**（选题背景、文献综述、研究内容、研究方法、进度安排）+ 参加开题答辩。
- 目的：向导师和专家组确认"研究什么、怎么研究"，方向正式定下来。
- 注意：
  - 开题之后原则上**不大改方向**，改方向=重新开题，时间成本极高。
  - 开题没通过要重新开题，务必认真准备。

### 2. 中期检查（一般研二下）
- 做什么：向导师/学院汇报论文进展，提交中期报告。
- 目的：确认能按时毕业，发现进度问题及时调整。
- 常见风险点：此时发现方向做不下去、数据/资料不够，还来得及补救。

### 3. 预答辩（研三上）
- 做什么：正式答辩前，学院内部模拟答辩，老师们提修改意见。
- 目的：提前暴露问题，别把问题留到正式答辩。
- 预答辩被"毙"的情况较少，但意见要全部消化修改。

### 4. 盲审 / 外审（研三上到研三下之间）
- 做什么：论文送校外专家**匿名评审**（专家不知道你是谁）。
- 结果分：通过 / 修改后通过 / 不通过。
- 注意：
  - 盲审不过可能**延毕**，是最大的坎之一。
  - 不通过一般有一次修改后重新送审的机会，按意见认真大改。

### 5. 正式答辩（研三下）
- 做什么：答辩委员会听取汇报、提问、投票决定是否通过。
- 通过后按意见修改论文，提交最终版。

### 6. 学位申请（答辩后）
- 流程：答辩通过 → 提交学位申请材料 → 学院学位评定分委员会 → 校学位评定委员会 → 授予学位。
- 注意：答辩通过 ≠ 一定拿到学位证，学位评定委员会有最终决定权（一般不会卡正常毕业的人）。

---

## 三、毕业的两大硬条件（三项缺一不可）

1. **课程学分**：修满培养方案要求的学分（挂科/漏修要补）。
2. **学术成果**：达到学院发表要求（如"一篇 CSSCI"/"一篇 SCI"），见刊或录用。
3. **学位论文**：大论文查重合格 + 盲审通过 + 答辩通过。

> 常见误区：只盯着写大论文，忘了小论文要求；或只顾发论文，忘了学分。

---

## 四、常见风险与延毕原因

| 风险 | 说明 |
|---|---|
| 学分没修满 | 研一不重视选课，毕业前才发现缺学分 |
| 小论文没达标 | 卡在"见刊/录用时间点"，投稿太晚 |
| 大论文没写完/质量不够 | 拖延，或中途大幅改方向 |
| 盲审不通过 | 论文质量或格式问题 |
| 查重超标 | 引用不规范、大段复制自己已发表内容 |
| 与导师沟通不畅 | 方向反复、需求不明确 |

---

## 五、倒推时间表（帮用户算时间）

- 小论文：投稿周期普遍 3-12 个月，检索再滞后 1-6 个月 → **至少提前 1 年准备**，研一下就要开始写。
- 大论文：写作一般需要半年以上 → 开题后（研二上）就要开始积累，别等研三。
- 盲审：一般在正式答辩前 1-3 个月送审。
- 建议动作：**入学第一学期**就做三件事：
  1. 读学校/学院培养方案，抄下毕业要求原文
  2. 问导师+师兄师姐"实际"要求（口径和文件常有出入）
  3. 把关键节点（开题/中期/盲审/答辩）写进自己的日历

---

## 六、常见问题

**Q1：什么时候开题？**
一般研二上，具体看学院安排。开题前要先把选题和文献综述准备好。

**Q2：小论文最晚什么时候要见刊？**
看学校要求写的是"见刊""录用"还是"检索"。以"见刊"为例，要倒推 3-12 个月投稿；研三才投稿基本来不及。

**Q3：盲审挂了怎么办？**
先冷静，看专家意见，一般有一次修改后重新送审的机会。最坏情况延毕，按意见大改后争取通过。

**Q4：怎么知道我们学校的毕业要求？**
三查：研究生培养方案 / 学院学位授予细则 / 导师和师兄师姐。以白纸黑字为准。

**Q5：研二了还没发论文，来得及吗？**
视学校和期刊而定，先确认"录用"是否算达标。若算，立刻确定选题→写→投，还有机会；若要求见刊，需要和导师商量对策（如先投审稿快的期刊）。
